# Политика конфиденциальности Sensemark

[English](PRIVACY.en.md)

**Дата вступления в силу:** 31 июля 2026 г.

Sensemark — независимое open-source Chrome-расширение, не связанное с OpenAI и
не одобренное ею.

## Какие данные обрабатываются

Только для явно запрошенного перевода:

- текст, который пользователь выделил, ввёл или вставил;
- для короткого неоднозначного фрагмента — до 800 кодовых точек ближайшего
  текстового блока;
- пользовательский API‑ключ OpenAI;
- локальные настройки provider/model, режима выделения, карточки и согласия;
- результат и параметры перевода во временном session cache.

Расширение не отправляет URL или title страницы, историю посещений, ссылки,
произвольные `data-*`-атрибуты, изображения, canvas, скриншоты или содержимое
всей страницы. Стандартные `aria-label`, `aria-labelledby`, `alt`, `title` и
связанные `<label>` могут использоваться локально только как ограниченные
accessibility-кандидаты для восстановления текста текущего выделения. Sensemark
не выполняет OCR.

## Передача данных

Текст и ограниченный контекст отправляются напрямую из браузера на
`https://api.openai.com` по HTTPS только для перевода. API‑ключ передаётся
OpenAI в заголовке авторизации. До первого запроса пользователь должен явно
дать согласие; после его отзыва новые запросы блокируются.

У Sensemark нет сервера разработчика. Разработчик не получает тексты или ключи,
не продаёт данные, не использует их для рекламы и не разрешает людям читать
данные пользователей. OpenAI обрабатывает запросы по своим
[правилам данных API](https://developers.openai.com/api/docs/guides/your-data)
и [политике конфиденциальности](https://openai.com/policies/privacy-policy/).

## Локальное хранение

API‑ключ, настройки и согласие хранятся в `chrome.storage.local`.
API‑ключ доступен только доверенным страницам расширения и не передаётся content
script. Как и любой секрет, сохранённый клиентским расширением, он защищён
границами профиля Chrome, а не отдельным аппаратным хранилищем. Временный cache
хранится в `chrome.storage.session`: ключ записи хэшируется SHA‑256, срок — до 6
часов, максимум 200 записей и 2 MiB. Side-panel fallback может кратковременно
хранить выбранный текст в session storage в записи конкретных tab/frame/request;
запись имеет TTL и удаляется после чтения, ошибки открытия панели или закрытия
вкладки.

Sensemark не ведёт постоянную историю переводов, аналитику, advertising ID или
серверные журналы разработчика.

## Управление данными

В настройках можно явно удалить API‑ключ, отозвать согласие и сбросить настройки
карточки. Удаление расширения удаляет его local/session storage средствами
Chrome. Не отправляйте секреты или материалы, которые вы не имеете права
передавать OpenAI.

## Limited Use

Использование данных соответствует
[Chrome Web Store User Data Policy](https://developer.chrome.com/docs/webstore/program-policies/policies),
включая Limited Use. Данные используются только для функции перевода, не для
рекламы, кредитоспособности или несвязанных целей.

Существенные изменения публикуются здесь с новой датой. Вопросы:
[issues](https://github.com/StrangerOfDawah/sensemark/issues).
