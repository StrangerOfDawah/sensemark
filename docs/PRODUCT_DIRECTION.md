# Направление продукта

Sensemark — спокойный универсальный переводчик выделенного текста на русский,
а не набор адаптеров для популярных сайтов.

## Ценность

- работает одинаково на статьях, документации, веб-приложениях, формах и
  доступных вложенных frames;
- доверяет явно выбранному пользователем тексту;
- даёт точный контекст короткому фрагменту, не отправляя всю страницу;
- показывает потоковый результат быстро, но не создаёт пустую карточку;
- оставляет выбор момента перевода пользователю;
- хранит ключ локально и не имеет сервера разработчика, аналитики или рекламы.

## Ближайшие приоритеты

1. Расширять corpus стандартных Selection/Range/Shadow DOM/form cases.
2. Измерять latency native fast path и частоту fallback.
3. Улучшать доступность карточки, keyboard drag alternatives и reduced motion.
4. Добавлять provider только после отдельного privacy/permission/UX решения.
5. Поддерживать совместимость schema migration и воспроизводимую публикацию.

## Не цели

- OCR, перевод изображений и чтение canvas;
- сбор содержимого всей страницы;
- история посещений или облачная история переводов;
- доменные исправления, точные селекторы и browser automation сайта;
- автоматическое исполнение инструкций из выделенного текста;
- прокси-сервер разработчика или общий API‑ключ.
