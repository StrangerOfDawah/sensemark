# Sensemark

Универсальное Chrome-расширение для перевода явно выделенного или введённого
текста на русский через собственный API‑ключ OpenAI.

## Возможности

- native-first выделение в обычном DOM, формах, открытом Shadow DOM и доступных
  вложенных frames;
- три режима: автоматический (по умолчанию), кнопка рядом с выделением и только ручной;
- меню и `Ctrl/⌘+Shift+Y`;
- потоковый plain-text перевод без накопительных chunk’ов;
- строгий структурированный ответ для короткого контекстного и смешанного
  текста;
- draggable/resizable Shadow DOM-карточка с flip/shift/clamp, копированием и
  оригиналом;
- popup с явной кнопкой и автозапуском только после paste;
- компактная плавающая карточка рядом с выделением — основной интерфейс;
- автоматический перевод включён по умолчанию, модификатор не нужен;
- строго привязанная к вкладке side panel — только для защищённых страниц;
- session TTL/LRU cache и отмена устаревшего запроса;
- API‑ключ недоступен content script;
- нет рекламы, аналитики, сервера разработчика и доменных правил.

## Как пользоваться

1. Откройте настройки Sensemark.
2. Введите собственный OpenAI API‑ключ с доступным API balance.
   Проверенная модель выбирается из списка; custom model помечается как
   совместимость, не подтверждённая до первого перевода.
3. Подтвердите отправку выбранного текста в OpenAI.
4. Выделите иностранный текст. В режиме по умолчанию нажмите появившуюся
   кнопку «Перевести».

Можно выбрать автоматический режим, использовать контекстное меню или
`Ctrl/⌘+Shift+Y`. На страницах, куда Chrome заведомо не пускает content script
(встроенный PDF-просмотрщик, `chrome://`, Web Store), Sensemark сразу открывает
side panel. Если на обычной странице выделение прочитать не удалось, расширение
покажет подсказку повторить команду: тихо открыть панель после этого нельзя, так
как Chrome уже мог снять user activation. Для ручного перевода нажмите иконку
расширения.

Подписка ChatGPT не включает API usage; стоимость определяется тарифами OpenAI.

## Приватность

В OpenAI отправляется только выделенный/введённый текст. Для короткого
неоднозначного фрагмента добавляется до 800 кодовых точек ближайшего текстового
блока. URL, title страницы, ссылки, произвольные `data-*`, изображения и
содержимое всей страницы не отправляются. Подробнее:
[политика конфиденциальности](PRIVACY.md).

## Разработка

Требуется Node.js 24 LTS; версия закреплена в `.nvmrc` и CI.

```bash
npm ci
npm test
npm run test:coverage
npm run check
npm run test:browser:auto
npm run package:extension
npm run package:source
npm run verify:reproducible
npm run verify:artifacts
```

Загрузите корень репозитория через `chrome://extensions` → Developer mode →
Load unpacked.
